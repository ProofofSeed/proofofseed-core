# Proof-byte pins: the streams this repository's circuits and prover produce, so that a
# change to either is seen rather than assumed. Each row is `name byte_length keccak256(stream)`.
#
# WHAT THIS FIXTURE IS, AND WHAT IT STOPPED BEING
#
# It began as the extraction acceptance: recorded from the untouched ledger-app tree at
# 86a4656, it showed that moving the circuits and the prover into this repository left
# every proof byte alone. That claim was established and it stands in the history — the
# fixture passed, unaltered, from the extraction through 6c5978c.
#
# It can no longer serve that purpose. ZKBoo 2.0.0 is a breaking format change (proof
# format version 3, an assertion word appended to every circuit's outputs, a rebuilt
# elliptic-curve comb), so no tree that exists today reproduces the 1.x bytes, and the
# second implementation to record from is long gone. Re-anchoring here is therefore
# circular with respect to the extraction, and the extraction is NOT what these rows
# assert any more. What they assert is narrower and still worth having: proof bytes do
# not move unless a change is meant to move them, and when one is, exactly the intended
# rows move and the others are seen not to.
#
# Re-anchored 2026-08-28 against ZKBoo 2.0.0. Eight of the nine rows moved:
#   - `raw/bip39-r2/n2` and the `derived/hardened_child/*` rows shrank, the hardened-child
#     ones by 32 B per response, which is that statement's witness (32 parent-key bytes)
#     appearing or not with the challenge — these responses are bimodal in size, so a row
#     moving by exactly one input share is a coin landing the other way, not a defect.
#   - `derived/slip10_child/n4/full` kept its length and changed digest: the `derived/`
#     rows key their prover entropy on the circuit fingerprint, which 2.0.0 moved.
#   - `raw/public_key/*` fell by 3.77x, the elliptic-curve reduction 2.0.0 was built for.
#   - `raw/master_key/n2` did NOT move, in length or digest. It is the one row whose
#     circuit 2.0.0 left alone and whose entropy is raw rather than derived, so it is the
#     control: a future change that claims to touch only the curve statements has to leave
#     this row exactly as it is.
#
